# Symplax docs

The public documentation for [Symplax](https://symplax.com), built with [Mintlify](https://mintlify.com).

## Preview locally

```bash
npx mintlify dev
```

Then open http://localhost:3000. Pushing to `main` publishes the site.

## Writing

Read [AGENTS.md](AGENTS.md) first: document only what Symplax really does, no em dashes, second
person, sentence case. Navigation and theme live in `docs.json`.
